# Vue Flow Storybook

Standalone Vue stories. These components, fixtures, and stories are local to this workspace; they do not use the shared React/Svelte story implementation.

From the repository root:

```sh
pnpm exec turbo run build --filter=@xyflow/vue
pnpm storybook:vue
```

Open http://localhost:6009. `pnpm storybook` also starts Vue alongside React, Svelte, and the combined sidebar on port 6008.

Build the static Storybook with `pnpm exec turbo run build-storybook --filter=storybook-vue`.

All 34 example pages are under `stories/examples`, with a story beside each example. The five former generic test configurations also have stories under `stories/examples/generic-tests`. Storybook replaces the old router and example picker. Vue auto-imports, the original example styles, and Pinia are configured in `.storybook`.

`stories/auto-imports.d.ts` is generated by the auto-import plugin and committed so typechecking also works before launching Storybook.
